PyKeys-Symbols
Quick access to programming symbols for Windows
PyKeys-Symbols is a small Windows utility that provides quick access to commonly used programming symbols.
The idea came from a common problem I noticed while learning Python: some programming symbols are difficult or inconvenient to type, especially when switching between German and English keyboard layouts.
How to use
Run pykeysfinal.exe.
Do not close the application. PyKeys continues running in the background.
When you need a programming symbol while writing code, press Ctrl + Alt + Y.
The PyKeys window appears on top of your current application.
Click the symbol you need.
The symbol is automatically copied to the clipboard, and the PyKeys window hides itself.
Return to your code and press Ctrl + V. The symbol will be inserted directly where you are typing.
For example:
Ctrl + Alt + Y → click [] → Ctrl + V
The [] symbols will appear directly in your code.
You do not need to restart the program every time. Keep PyKeys running in the background and use Ctrl + Alt + Y whenever you need a symbol.
The application can be used with different programming languages, not only Python.
Current version
This is the first working version of the project.
Automatic startup with Windows and further interface improvements are planned for future versions.

Быстрый доступ к символам программирования для Windows
PyKeys-Symbols — небольшая Windows-программа, которая позволяет быстро находить и вставлять часто используемые символы программирования.
Идея появилась во время обучения Python. Я заметил, что некоторые символы неудобно искать на клавиатуре, особенно при переключении между немецкой и английской раскладками.
Как пользоваться
Запустите pykeysfinal.exe.
Не закрывайте программу. После запуска PyKeys продолжает работать в фоновом режиме.
Когда во время написания кода понадобится специальный символ, нажмите Ctrl + Alt + Y.
Окно PyKeys появится поверх текущей программы.
Нажмите на нужный символ.
Символ автоматически скопируется в буфер обмена, а окно PyKeys скроется.
Вернитесь к своему коду и нажмите Ctrl + V. Символ вставится прямо в то место, где вы сейчас пишете.
Например:
Ctrl + Alt + Y → нажать [] → Ctrl + V
Квадратные скобки [] появятся непосредственно в вашем коде.
Каждый раз заново запускать программу не нужно. Оставьте PyKeys работать в фоновом режиме и вызывайте её комбинацией Ctrl + Alt + Y, когда понадобится нужный символ.
Программа может использоваться не только для Python, но и при работе с другими языками программирования.
Текущая версия
Это первая рабочая версия проекта.
В следующих версиях планируется добавить автоматический запуск вместе с Windows и улучшить интерфейс программы.
